# Cypherium

> Cypherium is a permissionless Layer-1 blockchain that bridges centralized (CeFi) and decentralized (DeFi) finance for real-world assets. It runs the CypherBFT hybrid consensus (GPU proof-of-work committee election + HotStuff BFT) for instant finality, is EVM/Solidity compatible, and markets ISO 20022 banking integration. Developers interact with it through an Ethereum-style JSON-RPC node API and a Coinbase Rosetta API implementation.

## APIs
- [Cypherium JSON-RPC](https://pubnodes.cypherium.io/rpc): Ethereum-compatible node JSON-RPC over HTTP/WS/IPC — eth, web3, net, personal, miner, txpool, admin namespaces (EVM chain ID 16166).
- [Rosetta Cypherium](https://github.com/cypherium/rosetta-cypherium): Coinbase Rosetta API (Data + Construction) reference implementation for exchange/wallet integration.
